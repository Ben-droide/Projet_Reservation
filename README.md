# 📅 ReservaPro

**ReservaPro** est une application web moderne de réservation en ligne. 
Elle permet aux utilisateurs de choisir un service, une date et un créneau horaire avec une interface élégante.

## ✨ Fonctionnalités
* ✅ **Réservation dynamique** : Choix du service (Coupe, Barbe, Soin).
* 🚫 **Anti-doublon** : Vérification en temps réel de la disponibilité du créneau.
* 🌓 **Mode Sombre** : Interface adaptable pour un meilleur confort visuel.
* 💾 **Persistance des données** : Sauvegarde locale via le LocalStorage.
* 📊 **Compteur intelligent** : Affichage du nombre total de réservations.
*    **PortFolio** : Ajout de photo 

## 🛠️ Technologies utilisées
* **HTML5 / CSS3** (Variables CSS, Flexbox, Animations)
* **JavaScript ES6** (Manipulation du DOM, LocalStorage)
* **Font Awesome** (Icônes)
* **Google Fonts** (Typographie Poppins)

## 🚀 Installation
1. Clonez ce dépôt.
2. Ouvrez `index.html` avec l'extension **Live Server** sur VS Code.
