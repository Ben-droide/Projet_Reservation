# 📅 ReservaPro

**ReservaPro** est une application web moderne de réservation en ligne. 
Elle permet aux utilisateurs de choisir un service, une date et un créneau horaire avec une interface élégante.

## ✨ Fonctionnalités
* 📅 **Réservation dynamique** : Système de prise de rendez-vous avec choix du service (Coupe, Barbe, Soin, Épilation).
* 🚫 **Anti-doublon** : Algorithme de vérification empêchant deux réservations sur le même créneau horaire.
* 🌓 **Mode Sombre** : Interface adaptative (Light/Dark mode) pour un confort visuel optimal.
* 💾 **Persistance des données** : Sauvegarde automatique des rendez-vous et du portfolio via le `LocalStorage`.
* 📊 **Compteur intelligent** : Suivi en temps réel du volume de réservations enregistrées.
* 📷 **Portfolio Interactif** : Galerie intégrée permettant l'importation, l'affichage et la suppression de photos de réalisations.
* 📱 **Design Responsive** : Interface optimisée pour une utilisation fluide sur mobile, tablette et ordinateur (CSS Grid).
* 🔀 **Navigation par onglets** : Menu fluide permettant de basculer instantanément entre la gestion et la galerie.

## 🛠️ Technologies utilisées
* **HTML5 / CSS3** (Variables CSS, Flexbox, Animations)
* **JavaScript ES6** (Manipulation du DOM, LocalStorage)
* **Font Awesome** (Icônes)
* **Google Fonts** (Typographie Poppins)

## 🚀 Installation
1. Clonez ce dépôt.
2. Ouvrez `index.html` avec l'extension **Live Server** sur VS Code.
